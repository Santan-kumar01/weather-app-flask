# Weather App using Flask 🌦️

A simple weather application built using Flask and Python Requests API.

## Features
- Search weather by city
- Live temperature
- Humidity details
- Weather condition
- Weather icon

## Technologies Used
- Python
- Flask
- HTML
- CSS
- OpenWeatherMap API

## Project Structure

```plaintext
weather_app/
│── app.py
│── requirements.txt
│── .env
│
├── templates/
│     └── index.html
│
├── static/
│     └── style.css
```

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/weather-app-flask.git
```

2. Install dependencies

```bash
pip install -r requirements.txt
```

3. Add API key in `.env`

```env
API_KEY=your_api_key_here
```

4. Run the app

```bash
python app.py
```

## Output

Open browser:
